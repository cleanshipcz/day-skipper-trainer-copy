# Nautical Terms content review basis

Reviewed 2026-08-01. The 20 Boat Parts questions and matching learner-facing
descriptions were checked as a set, with the depicted boat treated as one
example rather than a universal yacht configuration.

## Authoritative basis

- [World Sailing, Equipment Rules of Sailing 2025–2028](https://www.sailing.org/inside-world-sailing/rules-regulations/equipment-rules-of-%20sailing)
  is the normative terminology source. Part II defines a mainsail by its luff
  being set on the mainmast; a forestay by forward mast support; a backstay by
  aft mast support; a boom as a spar; and keel as a hull-appendage type. Those
  functional definitions avoid assuming masthead attachment, deck endpoint,
  ballast, or sail-foot attachment.
- [MAIB report 12/2018, *CV24*](https://assets.publishing.service.gov.uk/media/5b30ee7d40f0b67f8511a514/2018_-_12_-_CV24.pdf)
  supplies operational yacht terminology for boom, foot, halyard, sheet,
  heading and running backstay, and reinforces that rig arrangements can use
  paired running backstays.
- [Transport Canada TP 14609, section 4.1](https://tc.canada.ca/en/marine-transportation/publications/tp-14609-study-guide-applicants-fourth-class-engineer-certificate-stcw-endorsement)
  defines keel in its broader structural sense. Together with World Sailing's
  appendage taxonomy, it shows why “heavy underwater fin” is not a general
  definition.

## Review record

| Question | Review result |
| --- | --- |
| Bow / stern | End-of-vessel definitions retained; stern no longer implies a universal rudder or helm location. |
| Port / starboard | Forward-facing left/right and red/green associations retained. |
| Beam | Maximum-width meaning retained. |
| Hull / deck | Body and working-surface distinctions retained. |
| Keel | Recast around lateral resistance; ballast, fin form and righting contribution are explicitly configuration-dependent. |
| Rudder / tiller | Steering blade and tiller-direction questions retained for ahead motion. |
| Mast | Vertical spar and sail/rig support distinction retained. |
| Boom | Recast as an aft-extending mainsail-control spar; loose-footed mainsails are not excluded. |
| Mainsail | Recast using the mainmast/luff relationship; no largest-sail or principal-driving-force claim. |
| Jib | Headsail set forward of the mast retained. |
| Forestay / backstay | Recast by forward/aft support function; masthead and bow/stern endpoints are not required. |
| Shrouds / spreaders | Transverse support and compression-strut functions retained. |
| Telltales | Airflow indication retained without making them the sole trim criterion. |
| Cockpit | Recessed crew/controls area retained as a typical rather than mandatory helm location. |

Each quiz item was also checked for four distinct options, an in-range answer
index, and one best answer. The Boat Parts text and quiz now use the same
configuration-aware distinctions, while preserving the jib/forestay geometry
established by issues #142 and #147.
